Search pipeline

A question becomes a 384-dimension vector, Db2 ranks the stored chunks by cosine distance, and the top matches are pasted into a prompt for the local chat model. Four components: OpenAITextEmbedder → IBMDb2EmbeddingRetriever → ChatPromptBuilder → OpenAIChatGenerator.
